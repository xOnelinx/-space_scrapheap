# Космическая свалка

2D-игра про скитальца в открытом космосе: обломки кораблей, мусор, астероиды и предметы, которые можно подобрать. Управление построено на инерции — **«лягушка в пустоте»**: клик задаёт направление, персонаж летит дальше, пока не сменит курс.

Подробная концепция и план шагов — в [`GAME.md`](GAME.md).

## Стек

**Godot 4.7** (GL Compatibility), GDScript, desktop 1280×720. Проект в `godot/`.

Бинарник: `~/.local/bin/godot` (4.7.x).

## Запуск

```bash
godot/run.sh
```

## Управление

| Действие | Управление |
| --- | --- |
| Толчок / оттолкнуться | ЛКМ к курсору, стоя на теле; сила — расстояние курсора от скитальца (ближе слабее, дальше сильнее) |
| Импульс в пустоте | Нет кнопки. В пустоте ЛКМ не толкает |
| Прицел прыжка | ПКМ — курс; сила на прицеле тоже от расстояния курсора; отпустить ПКМ — сброс, без прыжка |
| Ходьба по телу (после посадки) | A / D |
| Гарпун: выстрел | E в сторону курсора. Импульс герою назад и телу в точке попадания. От камня отлетают газ и песок |
| Гарпун: втянуть | Удерживать E. Трос короче, скитальца тянет к телу. Длина не больше 30 его размеров |
| Второй конец троса | СКМ, стоя на астероиде, когда крюк уже сидит. Конец садится на железо, от камня отлетают газ и песок. Длина замирает. Натянутый трос держит камни, слабый провисает и не гасит их ход. У героя новый трос |
| Снять трос | Q снимает только трос в руках, без вспышки |
| Трос между камнями | F рядом с закреплённым тросом — сесть на него боком с той стороны, с которой подошёл, руки сжимают трос как астероид; A и D — ехать к концам. F у конца троса сажает на камень этого конца, в периметре астероида сажает на него, в пустоте отпускает трос |
| Люк корпуса | F на обломке — внутрь; F внутри — наружу. Рядом с закреплённым тросом F сажает на трос |
